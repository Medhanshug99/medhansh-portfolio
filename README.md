# Medhansh Poojari - Software & ML Engineer Portfolio

A personal portfolio showcasing my expertise as a Software & ML Engineer. The platform highlights my full-stack applications and AI-integrated platforms, such as DocuParse AI (using LayoutLMv3 and Pinecone for semantic search) and IntellMeet (leveraging Whisper and fine-tuned LLMs for technical interview simulations). Built with React, Vite, and Tailwind CSS v4, the site features a modern, responsive UI with Framer Motion animations and serverless functions via Vercel for real-time contact management and visitor tracking.

## Visit
[Live Portfolio](https://medhanshdevv.vercel.app/)

## Tech Stack
- **Frontend**: React, Vite, Tailwind CSS v4, Framer Motion
- **Backend & APIs**: Node.js, Vercel Serverless Functions, Neon Postgres
- **AI & ML**: PyTorch, LayoutLMv3, Whisper, wav2vec2, Pinecone, LangChain
- **Other**: EmailJS, React Icons

## Local Development
1. Clone the repository
2. Run `npm install`
3. Configure environment variables in `.env` (EmailJS API keys and Neon Database URL)
4. Run `npm run dev` to start the development server
